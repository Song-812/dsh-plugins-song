# 插件侧栏 · dsh-plugins-panel

[English](README.en.md) | 简体中文

给 DSH 侧栏加一个「插件」页：只列「自制」一组插件（DSH 内置整组不显示），每个插件一个启用/停用开关。
支持分组折叠、分组头一键开关、拖动排序与搜索，以及「官方管理页」跳到官方安装/卸载/配置页。显示偏好（含旧版已保存的自定义标题/简介/分组名，仅继续显示、不再提供编辑）写在插件自己的状态文件里。开关走 DSH 官方 `pluginManager.setPluginEnabled`，热重载该行，无需重启。

- 版本：0.2.1

## 为什么不列内置插件

拨动 DSH 内置条目时，官方管理器会把它们写进 profile 的 patch 并热重载，既写脏文件又容易刷报错。本页因此**只列自制一组**；要看 / 装 / 卸内置那些，请走「官方管理页」。

## 开关与状态

| 控件 | 作用 |
| --- | --- |
| **状态点** | 随该行启用状态与 fiber 阶段显示 |
| **开关** | 启用或停用这个插件（官方 Remote，即时生效）；不可寻址的行会锁住并显示原因 |

带 `patchId` 且没有 `readOnlyReason` 的行才可切换。`readOnlyReason` 只有两种：`management-required` / `unaddressable`。`setPluginEnabled` 返回后本页还会**回读清单核对**一次，确认那一行真的变成了想要的状态。

## 这一页还能怎么摆

| 控件 | 作用 |
| --- | --- |
| **六点手柄（行首）** | 按住进入拖动，在**组内**排序；拖到上下边缘会自动滚动 |
| **分组头手柄** | 拖动整组（当前通常只有「自制」一组，松手回原位） |
| **折叠 / 展开** | 只改界面；折叠状态会记住 |
| **一键旋钮（分组头右侧）** | 整组一起开 / 一起关；读不到或失败的行跳过并计数；旋钮方向会锁存 |
| **搜索** | 匹配原名、旧版自定义名、包名、简介等（不区分大小写；搜索词不落盘） |
| **恢复默认** | 清掉自定义名、简介、排序、折叠等显示偏好（会先确认）；插件开关不动 |
| **官方管理页** | 打开官方插件页（安装 / 卸载 / 配置 / 详情） |

> 标题、简介、分组名的**铅笔编辑入口已移除**。若状态文件里还留着旧版自定义名，页面会继续显示，但不能再改。要改请直接编辑状态文件，或点「恢复默认」。

## 与官方页的关系

官方那个「插件」页**本体一动不动**：不影子、不改它的 DOM、不动它的能力。

- 侧栏入口的隐藏方式：靠本插件图标上的标记认出「哪个是我」，再隐藏「同层 + 同 `aria-label` + 不是我」的按钮；认不到就用兜底规则；**两套都认不到就什么都不做**。
- 本插件被停用 / 卸载时，清理函数会把官方入口**还原**。

## 原理与数据来源

| 环节 | 用什么 |
| --- | --- |
| 插件清单与启用状态 | `remote.pluginManager.listPlugins()`（与官方插件页同一个 Remote） |
| 「自制」判定 | 宿主半读 profile 的 `package.json`，`dependencies` 里值是 `link:` / `file:` 开头的算自制 |
| 开关 | `remote.pluginManager.setPluginEnabled(entryId, enabled)` |
| 显示偏好 | 宿主半 `GET/POST /api/plugins-panel` ↔ `~/.dsh/plugins-panel.json`（或 `$DSH_HOME/plugins-panel.json`）的 `prefs` |

**宿主半只写显示偏好**（`prefs`）。插件文件、profile、开关状态它一个都不碰——开关由面板调官方 Remote 完成。

## 显示偏好存在哪

只存在插件自己的状态文件 `~/.dsh/plugins-panel.json` 的 `prefs` 字段（标题、简介、分组名、排序、折叠、旋钮方向）。**不写** profile 的 `cordis.patch.yml`（开关覆盖由官方 Remote 写）、也不写别的插件的文件。

换电脑或删掉状态文件，摆布会丢；各插件本身的启用状态不受影响。

## 文件结构

| 路径 | 作用 |
| --- | --- |
| `lib/index.js` | 宿主半：自制/内置判定、状态文件（含 `prefs`）、`/api/plugins-panel` |
| `lib/client.js` | 客户端半：侧栏「插件」页（含隐藏官方入口）；手写、无构建 |
| `cordis.patch.yml` | 插件行声明 |
| `test/*.mjs` | 离线自测（含 host/client smoke） |

## 安装与开发

安装：在 DSH 插件面板装本目录，或 `plugin_manager install_bundle` 指向包目录。

插件自带 `cordis.patch.yml`；profile 自己的 `cordis.patch.yml` **不要**再插一次同样的行（重复行 id 可能导致启动失败）。

改了 `lib/client.js` 要刷新页面；改了 `lib/index.js` **必须重启一次 DSH**（或重新启用插件行）。重启前页面能显示，但保存偏好可能失败并提示 HTTP 405。

```bash
cd plugins-panel
npm test   # node --test（会跑 test/ 下全部用例，含 host/client smoke）
```

`node --test` 会跑 `test/` 下的脚本。两条 smoke 分别覆盖宿主半（临时目录闭环）和客户端半（假 React / 迷你渲染器），都不需要真开 DSH 或浏览器。

## 已知限制

1. 只能**开关**插件，不能安装 / 卸载 / 配置 —— 那些在官方管理页。
2. 官方清单接口是「只读清单 + 单个开关」；本页靠 `remote.$on("plugin-manager/changed")` 跟着刷新。
3. 行简介只存在本页，**不会**同步到任何插件文件，也不影响模型。
4. 同一行重复出现在多个 profile 层时以 DSH 自己的清单为准，本页不推断。
5. 拖动手感依赖真实指针；离线测试只覆盖逻辑，不替代真机手感。
