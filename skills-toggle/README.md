# 技能侧栏 · dsh-skills-toggle

[English](README.en.md) | 简体中文

给 DSH 侧栏加一个「技能」页：按技能单独开关「模型可调用 / 仅手动」，并按「我的技能 / 本项目 / ChatCut」三栏摆开。
支持分组折叠、分组头一键开关、拖动排序与搜索。显示偏好（含旧版已保存的自定义标题/分组名，仅继续显示、不再提供编辑）写在插件自己的状态文件里。开关写入 `SKILL.md` 的 front matter，带注册表校验与自动回滚。

- 版本：0.3.1
- 许可证：MIT

## 两个开关

| 开关 | 关掉之后 |
| --- | --- |
| **模型** | 模型看不到这个技能，也不能调用它（下一步就生效） |
| **手动** | 你在输入框的 `/` 技能菜单里也看不到它 |

两个开关相互独立：只关「手动」时，模型仍然可以正常调用它。

## 这一页还能怎么摆

| 控件 | 作用 |
| --- | --- |
| **六点手柄（行首）** | 按住约 300ms 进入拖动，在**组内**排序；拖到上下边缘会自动滚动 |
| **分组头手柄** | 拖动时整个分组连同组内条目一起走 |
| **折叠 / 展开** | 只改界面，不碰任何技能文件；折叠状态会记住 |
| **一键旋钮（分组头右侧）** | 整组一起开 / 一起关；失败的行跳过并计数，旋钮方向会锁存 |
| **搜索** | 同时匹配原名、旧版自定义名和描述 |
| **恢复默认** | 清掉排序、折叠等显示偏好（会先确认）；技能文件里的开关不动 |

> 标题、简介、分组名的**铅笔编辑入口已移除**。若状态文件里还留着旧版自定义名，页面会继续显示，但不能再改。

## 三栏怎么分

- **我的技能**：`~/.dsh/skills`
- **本项目**：`<项目>/.dsh/skills`、以及受管的官方 runtime 技能目录
- **ChatCut**：`~/.agents/skills` 里属于 ChatCut 桌面应用的技能

ChatCut 归属由宿主半判定（清单文件或 `chatcut-` 前缀），结果随清单下发。这些技能不会再出现在「本项目」里。

## 原理

DSH 没有单独的技能开关 API，但技能发现器认 `SKILL.md` front matter：

| 键 | 开启 | 关闭 |
| --- | --- | --- |
| `disable-model-invocation` | **删掉该行**（缺省即允许） | 写 `true` |
| `user-invocable` | 写 `true`（或还原作者原本那一行） | 写 `false` |

关→开时会尽量把作者原本那一行原样放回，所以本来没有那一行的技能，关掉再打开后文件可与原始状态逐字节一致。

## 安全设计（摘要）

1. **写入后立刻回读并重新解析**；不符就回滚成写入前的字节，并在界面标红。
2. **与 DSH 注册表核对**：没生效就把该行置灰并写明原因。
3. **只允许写受管技能目录里的技能文件**；其他路径一律拒绝。
4. **原子替换**（临时文件再改名）；BOM / CRLF / 引号 / 缩进尽量原样保留。
5. 接口走 DSH `/api` 通道，带 Host/Origin 围栏与浏览器鉴权。

## 显示偏好存在哪

只存在插件自己的状态文件 `~/.dsh/skills-toggle.json` 的 `prefs` 字段（标题、分组名、排序、折叠）。**不写**技能正文、不写 profile 的 `cordis.patch.yml`、也不写别的插件的文件。

换电脑或删掉状态文件，摆布会丢；写在 `SKILL.md` 里的开关状态不受影响。

## 文件结构

| 路径 | 作用 |
| --- | --- |
| `lib/index.js` | 宿主半：扫技能、改 front matter、状态文件（含 `prefs`）、`/api/skills-toggle` |
| `lib/client.js` | 客户端半：侧栏「技能」页；手写、无构建 |
| `cordis.patch.yml` | 插件行声明 |
| `test/*.mjs` | 离线自测（含 host/client smoke） |

## 安装与开发

安装：在 DSH 插件面板装本目录，或 `plugin_manager install_bundle` 指向包目录。

改了 `lib/client.js` 要刷新页面；改了 `lib/index.js` **必须重启一次 DSH**（或重新启用插件行）。

```bash
cd skills-toggle
npm test   # node --test（会跑 test/ 下全部用例，含 host/client smoke）
```

`node --test` 跑 `*.test.mjs`；两条 smoke 分别覆盖宿主半（临时目录闭环）和客户端半（假 React / 迷你渲染器），都不需要真开 DSH 或浏览器。

## 已知限制

- 没有活跃会话时无法与注册表核验；界面仍可开关，顶部会标明未核验。
- 客户端 `/` 菜单有会话级缓存：关掉「手动」后，当前会话菜单可能要刷新或切换预设才更新。
- 同名技能（不同目录）无法逐项核验，会被锁住；一键旋钮也会跳过它们。
- 关掉项目技能会改项目里的文件，`git` 可能显示改动。
- ChatCut 技能是外部应用装的：关掉会真改那些 `SKILL.md`；ChatCut 更新可能覆盖标记。
- 拖动手感依赖真实指针；离线测试只覆盖逻辑，不替代真机手感。
